Бағдарламаның орындалуын қадамдап бақылаңыз (trace). Кестенің әр жолы — бір оператор (statement). Әр жол орындалғаннан КЕЙІНГІ толық жағдайды жазыңыз: «Стек» бағанына — стектегі (stack) барлық фреймдерді және олардағы айнымалыларды, «Үйінді» бағанына — үйіндідегі (heap) барлық объектілерді. Әр жол — 4 ұпай (2 + 2).
Белгілеулер:
- сілтеме (reference) — a→1; бос сілтеме — b=null;
- үйіндідегі объект — 1 Alma объекті (salmaq=0);
- бірде-бір сілтеме арқылы жетуге болмайтын объект — «— GC кандидаты»;
- стекте фреймдер жоғарыдан төмен жазылады, ең үстінде — қазір орындалып жатқан әдіс немесе конструктор: tekser(): b=7 / main(): o→1; айнымалысы жоқ фрейм — getJas(): —;
- конструктордың (constructor) фреймі — Alma(): s=5 (this жазылмайды); Object() конструкторы жазылмайды;
- «(… ішінде)» — шақырылған әдістің немесе конструктордың денесіндегі оператор (return операторы да жеке жол); қайта жүктелген (overloaded) конструкторлар параметрлерімен ажыратылады: (Alma() ішінде), (Alma(int s) ішінде);
- super(…) және this(…) шақырулары жеке жол болып жазылмайды — тек конструкторлар денесіндегі операторлар жазылады;
- туынды класс (subclass) объектісінің өрістерін жазғанда базалық кластың (superclass) өрістері бірінші жазылады; әлі мән берілмеген өріс — 0 немесе null;
- «(қайтқаннан кейін)» — әдіс (немесе конструктор) аяқталып, оның нәтижесі айнымалыға меншіктелгеннен кейінгі жағдай (оның фреймі бұл кезде стекте жоқ);
- void әдісті шақыру жеке жол болып жазылмайды — тек оның денесіндегі операторлар жазылады.

Кодтағы ? белгісінің орнына қойылатын мән (жасалатын объектілер саны, конструктор (constructor) аргументтері) — тесттің кірісі (input). 4 ТЕСТ ойлап табыңыз. Әр тест үшін жазыңыз:
1. кіріс мәні — әр ? орнына қандай мән қойылады;
2. күтілетін нәтиже (expected result) — талап (requirement) бойынша бағдарлама экранға не шығаруы керек;
3. тест нені тексереді — қай конструктор орындалады (қайта жүктелген (overloaded) конструкторлардың қайсысы таңдалады, super(...) немесе this(...) арқылы конструкторлар қандай ретпен шақырылады), if-тің қай тармағы орындалады, қай шекара (boundary) тексеріледі.

Тесттер әртүрлі жағдайларды тексеруі керек. Егер бағдарлама талапқа сай келмейтін тест тапсаңыз, оны көрсетіңіз. Әр тест — 8 ұпай (кіріс 2 + күтілетін нәтиже 3 + нені тексереді 3), қорғау (defense) — 12 ұпай.

import java.util.ArrayList;

class Bolshek {                    // бөлшек (SimUnit)
  String turi;

  Bolshek(String t) {
    turi = t;
  }

  int quat() {                     // қуат шығыны (power use)
    if ("jyly".equals(turi)) {
      return 3;
    } else {
      return 5;
    }
  }
}

class SalqynV2 {                   // салқындатқыш, 2-нұсқа (V2Radiator)
  SalqynV2(ArrayList<Bolshek> tizim) {
    for (int i = 0; i < 2; i++) {
      tizim.add(new Bolshek("V2"));
    }
  }
}

class SalqynV3 extends SalqynV2 {  // салқындатқыш, 3-нұсқа (V3Radiator)

    super(tizim);
    for (int i = 0; i < 3; i++) {
      tizim.add(new Bolshek("V3"));
    }
  }
}

class JylyBot {                    // жылу сақтаушы бот (RetentionBot)
  JylyBot(ArrayList<Bolshek> tizim) {
    tizim.add(new Bolshek("jyly"));
  }
}

public class JuieTest {
  public static void main(String[] args) {

    int a = ?;                     // тест кірісі: SalqynV2 объектілерінің саны
    int b = ?;                     // тест кірісі: SalqynV3 объектілерінің саны
    int c = ?;                     // тест кірісі: JylyBot объектілерінің саны

Талап: a, b, c — 0-ден 3-ке дейінгі бүтін сандар: a — SalqynV2, b — SalqynV3, c — JylyBot объектілерінің саны.     salmaq = s;
    System.out.println("3-tip qaz");
  }

  public Qaz(int j, boolean u) {
    jyldamdyq = j;
    ushady = u;
    System.out.println("4-tip qaz");
  }

  void korset() {
    System.out.println("salmaq=" + salmaq + " qalqu=" + qalqu
        + " jyldamdyq=" + jyldamdyq + " ushady=" + ushady);
  }
}

public class QazTest {
  public static void main(String[] args) {
    Qaz q = new Qaz(?, ?);         // тест кірісі: екі аргумент
    q.korset();
  }
}

Талап: ? орнына Qaz класының төрт конструкторының біріне типтері мен реті бойынша дәл сәйкес келетін екі литерал қойылады (int; float — F әрпімен, мысалы 2.5F; немесе boolean). Бағдарлама алдымен таңдалған конструктордың нөмірін шығарады, содан кейін қаздың төрт өрісін: «salmaq=… qalqu=… jyldamdyq=… ushady=…». Әр конструктор аргументтерінің мәндерін сәйкес өрістерге жазады: 1-tip (int, float) — salmaq, qalqu; 2-tip (float, int) — qalqu, jyldamdyq; 3-tip (boolean, int) — ushady, salmaq; 4-tip (int, boolean) — jyldamdyq, ushady. Қалған өрістер бастапқы мәндерін сақтайды: salmaq=6, qalqu=2.1, jyldamdyq=25, ushady=true.

class Qus {                        // құс (базалық класс)
  Qus(String turi) {
    System.out.println(turi + " jasaldy");
  }
}

class Uirek extends Qus {          // үйрек (Duck2)
  int olshem;                      // өлшем (size)

  Uirek() {
    this(12);                      // әдепкі өлшем (default size)
    System.out.println("adepki uirek");
  }

  Uirek(int o) {
    super("uirek");
    if (o < 3) {
      olshem = 3;
      System.out.println("kishi: 3 qoiyldy");
    } else if (o < 30) {
      olshem = o;
    } else {
      olshem = 30;
      System.out.println("ulken: 30 qoiyldy");
    }
    System.out.println("olshem = " + olshem);
  }
}

public class UirekTest {
  public static void main(String[] args) {
    Uirek u = new Uirek(?);        // тест кірісі: бүтін сан немесе бос
  }
}

Талап: ? орнына бүтін сан қойылады немесе ештеңе қойылмайды (new Uirek() — аргументсіз конструктор). Үйректің рұқсат етілген өлшемі — 3-тен 30-ға дейін (екі шегі де кіреді). Әр жаңа үйрек жасалғанда алдымен «uirek jasaldy» жолы шығады. Өлшем рұқсат етілген аралықта болса, сол күйінде сақталады; 3-тен кіші болса — өлшем 3 болады және «kishi: 3 qoiyldy» шығады; 30-дан үлкен болса — өлшем 30 болады және «ulken: 30 qoiyldy» шығады. Содан кейін «olshem = X» жолы шығады. Аргументсіз жасалған үйректің өлшемі — 12 (әдепкі), және ең соңында «adepki uirek» жолы шығады.
