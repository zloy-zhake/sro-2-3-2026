class Muzykant {

  }
}

class Dombyrashy extends Muzykant {

public class Sahna {
  public static void main(String[] args) {

    b.sahnada = true;                        // 2-жол

5. Dombyrashy объектісінде бір ғана дана айнымалысы бар — ishekSany, себебі sahnada өрісі Dombyrashy класының ішінде жазылмаған. (4 ұпай)

Бағдарламаны оқыңыз.

class Qurylgy {
  public boolean qosu() {
    System.out.println("Qurylgy qosyldy");
    return true;
  }
  public boolean oshiru() {
    System.out.println("Qurylgy oshti");
    return false;
  }
}

class Shainek extends Qurylgy {
  public boolean qosu(String rejim) {                  // A-жол
    System.out.println("Shainek qosyldy: " + rejim);
    return true;
  }
  public boolean oshiru() {                            // B-жол
    System.out.println("Shainek oshti");
    return false;
  }
}

public class AsUi {
  public static void main(String[] args) {
    Qurylgy q = new Shainek();
    q.qosu();                                          // C-жол
    q.oshiru();                                        // D-жол
  }
}

1. A-жолдағы qosu(String rejim) әдісі Qurylgy класындағы qosu() әдісін қайта анықтайды (overriding), себебі екі әдістің аты бірдей. (5 ұпай)
2. C-жол «Qurylgy qosyldy» шығарады, себебі Shainek класында параметрсіз qosu() әдісі жоқ, сондықтан Qurylgy класынан мұра етілген нұсқасы орындалады. (5 ұпай)
3. B-жолда public сөзін private сөзіне ауыстырсақ, код компиляцияланбайды, себебі қайта анықталған әдістің қолжетімділігі (access level) базалық кластағы (superclass) әдістен төмен бола алмайды. (5 ұпай)
4. D-жолдан кейін q.qosu("jyldam"); жолын қоссақ, код компиляцияланады, себебі q шын мәнінде Shainek объектісін көрсетеді, ал Shainek класында qosu(String) әдісі бар. (5 ұпай)
5. B-жолда boolean орнына int жазып, әдіс ішіндегі return false; жолын return 0; деп ауыстырсақ, код компиляцияланбайды, себебі қайта анықталған әдістің қайтару типі (return type) базалық кластағы әдістің қайтару типімен үйлесімді болуы керек. (4 ұпай)

Кестедегі «Код» бағанының әр жолы үшін екі бағанды толтырыңыз:
- «Компиляцияланады ма? Неге?» — «иә» немесе «жоқ» және себебі: қандай ереже бұзылады немесе неге бұл жол заңды (сілтеме типі, IS-A, мұрагерлік (inheritance), қайта анықтау (overriding), қайта жүктеу (overloading));
- «Не орындалады (не шығады) немесе қандай ерекше жағдай (exception)» — экранға шығатын мәтін (қай кластың әдісі орындалатынын көрсетіңіз) немесе қандай ерекше жағдай туындайды. Ештеңе шықпаса — «ештеңе шықпайды»; ерекше жағдай болмаса — «ерекше жағдай жоқ»; жол компиляцияланбаса — «—».
Әр жол — 4 ұпай (2 + 2).

Кодтағы ? белгісінің орнына қойылатын мән (объектінің класы, айнымалының типі немесе мәні) — тесттің кірісі (input). 4 ТЕСТ ойлап табыңыз. Әр тест үшін жазыңыз:
1. кіріс мәні — әр ? орнына қандай мән қойылады;
2. күтілетін нәтиже (expected result) — талап (requirement) бойынша бағдарлама экранға не шығаруы керек;
3. тест нені тексереді — қай класстың әдісі орындалады (қайта анықталған (overriding), мұраға алынған немесе базалық класс (superclass) нұсқасы), қай қайта жүктелген (overloading) әдіс таңдалады, қай шекара (boundary) тексеріледі.

Тесттер әртүрлі жағдайларды тексеруі керек. Егер бағдарлама талапқа сай келмейтін тест тапсаңыз, оны көрсетіңіз. Әр тест — 8 ұпай (кіріс 2 + күтілетін нәтиже 3 + нені тексереді 3), қорғау (defense) — 12 ұпай.

Талап: бағдарлама екі жол шығарады. 1-жол: ID — 1000-нан 9999-ға дейінгі бүтін сан (екі шеткі мән де кіреді); nomer осы аралықта болса, id өрісіне осы сан жазылады және ол шығады (мысалы, 1234), әйтпесе «qate» шығады. 2-жол: x пен y қосындысы; екеуі де int болса — нәтиже int (мысалы, 7), кемінде біреуі double болса — нәтиже double (мысалы, 7.0).
