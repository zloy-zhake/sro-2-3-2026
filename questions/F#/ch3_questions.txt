// Три функции без аннотации типа результата
let sum3 p q r =
    let s = p + q + r
    s

let labelOf p q =
    let text = p + "-" + q
    text

let scaled (p:float) q =
    let s = p * q
    s

4. В scaled аннотирован только p, поэтому для q компилятор выведет тип int — тип по умолчанию для арифметических операторов. (5 баллов)

// Электронная очередь к врачу: имена записанных пациентов
let queue = ResizeArray<string>()

let register name =
    if name = "" then "Error: empty name"
    elif queue.Count > 3 then $"Sorry, {name}, the queue is full"
    else
        queue.Add name
        $"{name} is number {queue.Count}"

Пояснение: ResizeArray — изменяемый список .NET. queue.Add name добавляет имя в конец списка, queue.Count — сколько имён в нём сейчас.

Требование (requirement): в очередь можно записать не больше 3 человек.
- Пустое имя "" не записывается, функция возвращает "Error: empty name".
- Если в очереди уже 3 человека, новый человек не записывается, функция возвращает "Sorry, <имя>, the queue is full".
