class Sanaq {
  public static void main(String[] args) {
    int[] upaylar = {4, 7, 2};
    int jinaq = 0;
    for (int u : upaylar) {
      jinaq = jinaq + u;
      u = 0;                               // A-жол
    }
    int k = 5;
    int m = k++ + 2;                       // B-жол
    int n = ++k;                           // C-жол
    System.out.println(jinaq + " " + upaylar[0] + " " + m + " " + k + " " + n);
  }
}

1. A-жол (u = 0;) upaylar массивінің элементтерін өзгертеді, сондықтан соңғы жолда upaylar[0] мәні ретінде 0 шығады. (5 ұпай)
2. B-жолдан кейін m = 7, ал k = 6, себебі k++ (постинкремент, post-increment) алдымен k-ның ескі мәнін өрнекке береді, содан кейін k-ны 1-ге арттырады. (5 ұпай)
3. C-жолдан кейін n = 6, себебі ++k (преинкремент, pre-increment) өрнекке k-ның ескі мәнін береді, ал k кейін ғана артады. (5 ұпай)
4. Цикл тақырыбын «for (String u : upaylar)» деп өзгертсек, код компиляцияланбайды, себебі цикл айнымалысының типі массив элементтерінің типімен үйлесімді (compatible) болуы керек. (5 ұпай)

class Sanau {

    for (int j = 3; j < 7; j++) {
      System.out.print(j + " ");
    }
    System.out.println();

3. while циклінің денесі кем дегенде бір рет орындалады, себебі while шартты дене орындалғаннан кейін тексереді. (5 ұпай)
4. Осы for циклін мағынасын өзгертпей while арқылы жазуға болады: «int j = 3;» циклге дейін, шарт «while (j < 7)», ал j++ цикл денесінің соңында. (5 ұпай)

Бағдарламаның орындалуын қадамдап бақылаңыз (trace). Кестенің әр жолы — бір оператордың (statement) бір рет орындалуы. Әр жол — 4 ұпай (2 + 2).
- «Айнымалылар мәндері» бағанына осы жол орындалғаннан КЕЙІНГІ барлық көрінетін (in scope) айнымалылардың (variables) мәнін жазыңыз. Шарт (condition) тексерілетін жолда (for, while, if) шарттың нәтижесін де (true/false) көрсетіңіз.
- for тақырыбы (header) екі түрлі жолмен беріледі: «кіру» — инициализация (initialization) және бірінші тексеру (boolean test); «i++; i < …» — итерация өрнегі (iteration expression) және келесі тексеру.
- «Шығыс» бағанына осы жол экранға шығаратын (output) мәтінді жазыңыз. Ештеңе шықпаса — «—». Бос орынды (space) «␣» белгісімен көрсетіңіз.

Кестені main() әдісінің операторлары үшін толтырыңыз. «Айнымалылар мәндері» бағанына orny, r айнымалыларын және k объектісінің soqqy өрісін (instance variable) — k.soqqy — жазыңыз. tekser() әдісінің ішін өз бетіңізше орындап, оның нәтижесін көрсетіңіз.

class Kema {
  private int[] torlar;
  private int soqqy = 0;

  public void setTorlar(int[] t) {
    torlar = t;
  }

  public String tekser(int boljam) {
    String natije = "miss";
    for (int tor : torlar) {
      if (boljam == tor) {
        natije = "hit";
        soqqy++;
        break;
      }
    }
    if (soqqy == torlar.length) {
      natije = "kill";
    }
    System.out.println(natije);
    return natije;
  }
}

class KemaTest {
  public static void main(String[] args) {
    int[] orny = {5, 6};
    Kema k = new Kema();
    k.setTorlar(orny);
    String r = k.tekser(6);
    r = k.tekser(4);
    r = k.tekser(6);
    if (r.equals("hit")) {
      System.out.println("passed");
    } else {
      System.out.println("failed");
    }
    r = k.tekser(5);
  }
}

Тесттер әртүрлі жағдайларды тексеруі керек. Егер бағдарлама талапқа сай келмейтін тест тапсаңыз, оны көрсетіңіз. Әр тест — 8 ұпай (кіріс 2 + күтілетін нәтиже 3 + нені тексереді 3), қорғау (defense) — 12 ұпай.

class Tiegish {
  void tie(int salmaq) {
    int jalpy = 0;
    int qoraptar = 0;
    for (int raund = 0; raund < 2; raund++) {
      int raundSalmaq = 0;
      for (int qalgan = 3; qalgan > 0; qalgan--) {
        raundSalmaq = raundSalmaq + salmaq;
        qoraptar++;
        if (raundSalmaq == 6) {
          break;
        }
      }
      jalpy = jalpy + raundSalmaq;
    }
    System.out.println(jalpy + " " + qoraptar);
  }
}

class TiegishTest {
  public static void main(String[] args) {
    Tiegish t = new Tiegish();
    t.tie(?);                      // тест кірісі: бір қораптың салмағы
  }
}

Талап: жүк 2 раундта тиеледі. Әр раундта қораптар бір-бірлеп тиеледі, бір раундта ең көбі 3 қорап. Барлық қораптың салмағы бірдей — 1-ден 10 кг-ға дейін. Раундта тиелген салмақ 6 кг-ға жеткенде немесе асқанда (≥ 6), осы раундта тиеу тоқтайды да, келесі раунд басталады. Соңында бағдарлама жалпы салмақты (jalpy) және қораптар санын (qoraptar) бос орын арқылы шығарады.
