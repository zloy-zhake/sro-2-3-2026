    // әр тізімдегі сөз саны

    int secondLength = secondList.length;

    int rand2 = randomGenerator.nextInt(secondLength);

    // сөз тіркесін құрастыру
    String dish = firstList[rand1] + " " + secondList[rand2];
    System.out.println("Бүгінгі мәзір: " + dish);
  }
}

1. rand2 айнымалысы 0, 1, 2 немесе 3 мәнін қабылдауы мүмкін. (5 ұпай)

public class AppleSong {
  public static void main(String[] args) {
    int applesNum = 3;
    String word = "apples";

    while (applesNum > 0) {
      if (applesNum == 1) {
        word = "apple"; // жекеше түр (singular)
      }
      System.out.println(applesNum + " red " + word + " on the tree");
      applesNum = applesNum - 1;

      if (applesNum > 0) {
        System.out.println("Now " + applesNum + " red " + word);
      } else {
        System.out.println("No more apples");
      }
    } // while соңы
    System.out.println("The end");
  }
}

1. while циклінің денесі (loop body) дәл 3 рет орындалады. (5 ұпай)
2. Бағдарламаның шығысында (output) «Now 1 red apple» жолы (жекеше түрде) бар. (5 ұпай)
3. «if (applesNum == 1)» орнына «if (applesNum = 1)» деп жазсақ, бағдарлама компиляцияланбайды. (5 ұпай)
4. «int applesNum = 3;» орнына «int applesNum = 0;» деп жазсақ, бағдарлама ештеңе шығармайды. (5 ұпай)
5. «applesNum + " red "» өрнегінің (expression) нәтижесі жол (String) болады. (4 ұпай)

- «Айнымалылар мәндері» бағанына осы жол орындалғаннан КЕЙІНГІ барлық айнымалылардың (variables) мәнін жазыңыз. Шарт (condition) тексерілетін жолда (while, if) шарттың нәтижесін де (true/false) көрсетіңіз.

ЖҮЙЕЛІК ДЕҢГЕЙ (44 ұпай)
======================================================================

Кодтағы ? белгісінің орнына қойылатын бастапқы мән — тесттің кірісі (input). 4 ТЕСТ ойлап табыңыз. Әр тест үшін жазыңыз:
1. кіріс мәні — ? орнына қандай сан қойылады;
2. күтілетін нәтиже (expected result) — талап (requirement) бойынша бағдарлама экранға не шығаруы керек;
3. тест нені тексереді — қай орындалу жолын (path), тармақты (branch) немесе шекараны (boundary).

Тесттер әртүрлі жағдайларды тексеруі керек. Егер бағдарлама талапқа сай келмейтін тест тапсаңыз, оны көрсетіңіз. Әр тест — 8 ұпай (кіріс 2 + күтілетін нәтиже 3 + нені тексереді 3), қорғау (defense) — 12 ұпай.

public class BallSong {
  public static void main(String[] args) {
    int balls = ?;          // жәшіктегі доптар саны (тест кірісі)
    String word = "balls";

    while (balls > 0) {
      if (balls == 1) {
        word = "ball";      // жекеше түр (singular)
      }
      System.out.println(balls + " " + word + " in the box");
      balls = balls - 1;
    }

    if (balls == 0) {
      System.out.println("Box is empty");
    }
  }
}

Талап: бағдарлама доп санын бастапқы мәннен 1-ге дейін кері санайды. Әр сан үшін «N balls in the box» жолын шығарады, ал N = 1 болса «1 ball in the box» деп шығарады. Соңында ӘРҚАШАН «Box is empty» жолы шығуы керек — бастапқы сан 0 немесе теріс болса да.

class Shuffle3 {
  public static void main(String[] args) {
    int x = ?;              // бастапқы мән (тест кірісі)
    while (x > 0) {
      if (x > 3) {
        System.out.print("z");
      }
      x = x - 1;
      System.out.print("+");
      if (x == 3) {
        System.out.print("y");
      }
      if (x == 1) {
        System.out.print("w");
        x = x - 1;
      }
    }
    System.out.println();
  }
}

Талап: x бастапқы мәні оң болса, бағдарлама әр айналымда (iteration) «+» шығарады және шығыс МІНДЕТТІ ТҮРДЕ «w» әрпімен аяқталады. x 3-тен үлкен айналымда «+» алдында «z» шығады, ал x 3-ке тең болған сәтте «+»-тан кейін «y» шығады. x ≤ 0 болса, тек бос жол шығады.
