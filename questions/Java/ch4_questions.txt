Бағдарламаның орындалуын қадамдап бақылаңыз (trace). Кестенің әр жолы — бір оператор (statement). Әр жол орындалғаннан КЕЙІНГІ толық жағдайды жазыңыз: «Стек» бағанына — стектегі (stack) барлық фреймдерді және олардағы айнымалыларды, «Үйінді» бағанына — үйіндідегі (heap) барлық объектілерді. Әр жол — 4 ұпай (2 + 2).
Белгілеулер:
- сілтеме (reference) — a→1; бос сілтеме — b=null;
- үйіндідегі объект — 1 Tazy объекті (jas=0);
- массив (array) — 1 Tazy[] массив объекті: [0]→2, [1]=null;
- бірде-бір сілтеме арқылы жетуге болмайтын объект — «— GC кандидаты»;
- стекте фреймдер жоғарыдан төмен жазылады, ең үстінде — қазір орындалып жатқан әдіс: setJas(): j=6 / main(): top→1; айнымалысы жоқ фрейм — getJas(): —;
- «(… ішінде)» — шақырылған әдістің денесіндегі оператор (return операторы да жеке жол);
- «(қайтқаннан кейін)» — әдіс аяқталып, оның нәтижесі айнымалыға меншіктелгеннен кейінгі жағдай (әдістің фреймі бұл кезде стекте жоқ);
- void әдісті шақыру жеке жол болып жазылмайды — тек оның денесіндегі операторлар жазылады.

Бастапқы күй берілген:
- Стек: main(): count=0, a→1, i=0
- Үйінді: 1 Aralas[] массив объекті: [0]=null, [1]=null
Кесте осы күйден кейін басталады. 1–7 жолдар — циклдің бірінші қайталануы (i = 0), 8-жол — екінші қайталанудың бірінші операторы.

public class Aralas {
  int sanaq = 0;

  public static void main(String[] args) {
    int count = 0;
    Aralas[] a = new Aralas[2];
    int i = 0;
    // ---- кесте осы жерден басталады ----
    while (i < 2) {
      a[i] = new Aralas();
      a[i].sanaq = a[i].sanaq + 1;
      count = count + a[i].mumkin(i);
      i = i + 1;
    }
  }

  public int mumkin(int index) {
    if (index < 1) {
      Aralas m = new Aralas();
      m.sanaq = m.sanaq + 1;
      return 1;
    }
    return 0;
  }
}

Кодтағы ? белгісінің орнына қойылатын мән (әдіс аргументі немесе өріс мәні) — тесттің кірісі (input). 4 ТЕСТ ойлап табыңыз. Әр тест үшін жазыңыз:
1. кіріс мәні — әр ? орнына қандай мән қойылады;
2. күтілетін нәтиже (expected result) — талап (requirement) бойынша бағдарлама экранға не шығаруы керек;
3. тест нені тексереді — қай орындалу жолын (path), тармақты (branch) немесе шекараны (boundary).

Тесттер әртүрлі жағдайларды тексеруі керек. Егер бағдарлама талапқа сай келмейтін тест тапсаңыз, оны көрсетіңіз. Әр тест — 8 ұпай (кіріс 2 + күтілетін нәтиже 3 + нені тексереді 3), қорғау (defense) — 12 ұпай.
