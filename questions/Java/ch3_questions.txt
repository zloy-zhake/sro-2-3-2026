Бағдарламаның орындалуын қадамдап бақылаңыз (trace). Кестенің әр жолы — бір оператор (statement). Әр жол орындалғаннан КЕЙІНГІ толық жағдайды жазыңыз: «Стек» бағанына — стектегі (stack) барлық айнымалыларды, «Үйінді» бағанына — үйіндідегі (heap) барлық объектілерді. Әр жол — 4 ұпай (2 + 2).
Белгілеулер:
- сілтеме (reference) — a→1; бос сілтеме — b=null;
- үйіндідегі объект — 1 Kitap объекті (bet=0);
- массив (array) — 1 Mysyq[] массив объекті: [0]→2, [1]=null;
- мән берілмеген жергілікті айнымалы (local variable) — uy (мән берілмеген);
- бірде-бір сілтеме арқылы жетуге болмайтын объект — «— GC кандидаты»;
- стекте фреймдер жоғарыдан төмен жазылады: main(): …

class Kitap {
  int bet;

  public static void main(String[] args) {
    Kitap a = new Kitap();
    a.bet = 120;
    Kitap b = new Kitap();
    Kitap c = a;
    c.bet = 300;
    a = b;
    b.bet = c.bet + 5;
    c = b;
  }
}

Цикл аяқталғандағы бастапқы күй берілген:
- Стек: main(): q→1, i=3
- Үйінді: 1 Oiynshy[] массив объекті: [0]→2, [1]→3, [2]→4, [3]=null; 2 Oiynshy объекті (nomer=1); 3 Oiynshy объекті (nomer=2); 4 Oiynshy объекті (nomer=3)
Кесте осы күйден кейін басталады. Массив элементтері қай жерде сақталатынына мұқият болыңыз.

class Oiynshy {
  int nomer;

  public static void main(String[] args) {
    Oiynshy[] q = new Oiynshy[4];
    int i = 0;
    while (i < 3) {
      q[i] = new Oiynshy();
      q[i].nomer = i + 1;
      i = i + 1;
    }
    // ---- кесте осы жерден басталады ----
    q[3] = q[2];
    q[2] = null;
    q[0] = q[3];
    Oiynshy k = q[1];
    q[1] = q[0];
    q[3] = null;
    k.nomer = q[0].nomer + 10;
    k = q[2];
  }
}

| № | Код                              | Стек | Үйінді |
|---|----------------------------------|------|--------|
| 1 | q[3] = q[2];                     |      |        |
| 2 | q[2] = null;                     |      |        |
| 3 | q[0] = q[3];                     |      |        |
| 4 | Oiynshy k = q[1];                |      |        |
| 5 | q[1] = q[0];                     |      |        |
| 6 | q[3] = null;                     |      |        |
| 7 | k.nomer = q[0].nomer + 10;       |      |        |
| 8 | k = q[2];                        |      |        |

ЖҮЙЕЛІК ДЕҢГЕЙ (44 ұпай)
======================================================================

Кодтағы ? белгісінің орнына қойылатын бастапқы мән — тесттің кірісі (input). 4 ТЕСТ ойлап табыңыз. Әр тест үшін жазыңыз:
1. кіріс мәні — әр ? орнына қандай мән қойылады;
2. күтілетін нәтиже (expected result) — талап (requirement) бойынша бағдарлама экранға не шығаруы керек;
3. тест нені тексереді — қай орындалу жолын (path), тармақты (branch) немесе шекараны (boundary).

Тесттер әртүрлі жағдайларды тексеруі керек. Егер бағдарлама талапқа сай келмейтін тест тапсаңыз, оны көрсетіңіз. Әр тест — 8 ұпай (кіріс 2 + күтілетін нәтиже 3 + нені тексереді 3), қорғау (defense) — 12 ұпай.

class Batyr {
  String esim;

  public static void main(String[] args) {
    int n = ?;                          // массив ұзындығы (тест кірісі)
    Batyr[] top = new Batyr[n];
    int z = 0;
    while (z < n) {
      z = z + 1;
      top[z] = new Batyr();
      top[z].esim = "сарбаз";
      if (z == 1) {
        top[z].esim = "Қабанбай";
      }
      if (z == 2) {
        top[z].esim = "Бөгенбай";
      }
      System.out.println(z + ": " + top[z].esim);
    }
  }
}

Талап: бағдарлама top массивінің барлық n элементін толтырып, әр элемент үшін «индекс: есім» жолын шығаруы керек. 1-индексті элементтің есімі — Қабанбай, 2-индекстісі — Бөгенбай, қалғандарының (0-индексті қоса) есімі — сарбаз. Бағдарлама қатесіз аяқталуы тиіс. n — теріс емес бүтін сан.

class Ushburysh {
  double audan;
  int biiktik;
  int negiz;

  public static void main(String[] args) {
    int[] b = {?};                      // биіктіктер (тест кірісі)
    int[] t = {?};                      // табандар (тест кірісі)
    Ushburysh[] tizim = new Ushburysh[b.length];
    int x = 0;
    while (x < b.length) {
      tizim[x] = new Ushburysh();
      tizim[x].biiktik = b[x];
      tizim[x].negiz = t[x];
      tizim[x].audanEsepte();

    audan = (biiktik * negiz) / 2;
  }
}

Талап: бағдарлама әр үшбұрыштың ауданын (биіктік × табан ÷ 2) дәл есептеп, «үшбұрыш индекс, аудан = мән» деп шығаруы керек. b мен t массивтерінің ұзындығы бірдей, мәндері — теріс емес бүтін сандар. Массивтер бос болуы мүмкін.

class Saiahat {
  public static void main(String[] args) {
    int[] index = {?};                  // қалалардың реті (тест кірісі)
